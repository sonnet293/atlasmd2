# ATLAS 탐사 기획 v0.3 ― 2026-11-01
방치형 포켓몬 탐사 게임 기획. 기존 배틀(battle)과는 별개의 콘텐츠이다.

핵심 반복은 **파견 준비 → 탐사 → 결과 확인 → 보급/제작/연구 중 소비 선택 → 다음 지역 개방**이다. 하루 1~2회, 회당 5~10분 확인으로 주요 성장이 가능하도록 한다. 짧은 탐사는 조합 시험, 긴 탐사는 생활 주기에 맞는 자원 수집이다.

## 설계 원칙
1. **모든 아이템은 획득처와 사용처를 동시에 가진다.** 사용처가 없는 소재는 만들지 않는다. 전체 사용처는 [아이템](item.md)의 "소재 사용처 대조표"에서 검증한다.
2. **해금은 단방향 그래프다.** SECTOR N을 여는 데 필요한 모든 재료는 N보다 먼저 열리는 지역에서만 나온다. ([성장과 해금](progression.md))
3. **상위 장비는 "더 강한 같은 것"이 아니라 "다른 문제의 답"이다.** 대응 장비는 지역 전용이고, 하위 지역 소재는 수리·열매·업그레이드·지역 연구에서 계속 소모된다.
4. **두 재화는 역할이 겹치지 않는다.** RP는 넓고 꾸준한 성장, AD는 좁고 깊은 성장. 서로 환전되지 않는다. ([경제](economy.md))
5. **선택에는 대가가 있다.** 장비 2칸(열매 포함), 경로 A/B, 특이 소재의 사용처(제작·등록·해독), 관측 데이터의 사용처(분석·제작·연구)는 모두 한쪽을 고르면 다른 쪽을 포기한다.
6. **방치형의 리듬을 지킨다.** 접속하지 않아도 손해가 커지지 않는다(보상 만료 없음, 일일 의뢰 이월). 능동 플레이는 "조금 더 빠르게" 할 뿐 "필수"가 아니다.

## 용어
| 용어 | 뜻 |
|------|------|
| 슬롯 | 동시에 파견 가능한 포켓몬 자리. 최대 3 |
| 구간 | 탐사 판정 단위. 15분 = 1구간, 구간마다 이벤트 1회 |
| 경로 | 지역마다 출발 전 고르는 A/B 탐사 방향. 드롭과 위험이 달라진다 |
| 위험 | 지역 고유의 사고. 상태 이상 또는 HP 피해 |
| 대응 장비 | 특정 지역 위험만 줄이는 장비 (Mk.I/Mk.II) |
| 지역 연구 | 지역마다 Lv1~5. 그 지역 누적 탐사 시간 + RP + 소재로 올리는 영구 성장 |
| 좌표 데이터 | SECTOR 해금에 소모되는 제작품 |
| RP / AD | Research Point / Anomaly Data. [경제](economy.md) 참고 |
