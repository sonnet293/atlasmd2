# SECTOR 01~09
관련 문서: [탐사 공통](../exploration.md), [해금](../progression.md), [아이템](../item.md)

- 지역마다 계정당 한 마리씩, 최대 3개의 서로 다른 지역에 동시 파견한다.
- 지역을 고른 뒤 포켓몬 1마리·경로 A/B·탐사 시간·장비 2칸(열매 포함)을 정하고, 각 파견은 독립적으로 종료한다.

## 타입 관계
| SECTOR | 추천 (기믹) | 면역·저항 | 취약 (피해 ×1.3) |
|---|---|---|---|
| 01 | 풀, 벌레, 비행 | 독·강철 (독 면역) | 페어리 |
| 02 | 물, 전기 | 물 (피해 −50%), 강철 (−25%) | 불, 바위 |
| 03 | 땅, 격투, 바위 | 불 (화상 면역), 물 (피해 −25%) | 풀, 얼음, 벌레 |
| 04 | 얼음, 불 | 얼음 (동결 면역), 불 (동결 확률 절반) | 풀, 땅, 드래곤 |
| 05 | 전기, 강철 | 땅 (마비 면역·방전 피해 0), 전기 (마비 면역) | 물, 비행 |
| 06 | 에스퍼, 고스트, 바위 | 에스퍼 (혼란 확률 절반), 바위·강철 (붕괴 피해 −40%) | 격투 |
| 07 | 악, 고스트, 전기·불 (집광) | 악·고스트 (수면 확률 절반) | 에스퍼, 페어리 |
| 08 | 비행, 드래곤 | 비행 (돌풍 피해 −50%), 드래곤 (−25%) | 바위, 강철 |
| 09 | 에스퍼, 드래곤 | 혼합 환경의 면역을 따름 | 혼합 환경의 취약을 따름 |

- 추천 타입과 면역·저항 타입이 다른 경우(01의 비행·벌레, 03의 땅·격투·바위, 05의 강철, 06의 고스트, 07의 전기·불)에 "보상 vs 안전" 선택이 생긴다. 반대로 겹치는 경우(02의 물, 04의 얼음, 05의 전기, 08의 비행)는 그 지역의 "정석" 타입이지만, 다른 지역에서는 취약해지는 경우가 많다(예: 비행은 05에서 취약).

## 문서 공통 형식
각 지역 문서는 다음 순서로 쓴다: 개요 → 해금 → 위험 → 경로 → 고유 기믹 → 이벤트 분포 → 드롭 테이블 → 탐사 시간별 특징 → 지역 연구 → 지속되는 역할.
